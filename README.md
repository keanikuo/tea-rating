# 品茶評分（tea-rating）專案說明

Gini 的私人專案。和朋友一起喝包種茶時（一次可能 20 杯以上），用手機快速記錄每一杯的評價，最後交叉比對出哪一杯最好。支援多人各自評分、主揪揭曉後一起看結果。

## 檔案

- `index.html`：整個 App（單一檔案，原生 JS，Firebase SDK 10.12.2 從 gstatic 載入）
- `firestore.rules`：Firestore 安全規則。**改了這個檔案不會自動生效**，要貼到 Firebase →「Firestore」→「規則」按「發布」
- `manifest.json`、`icon.svg`、`icon-192.png`、`icon-512.png`、`apple-touch-icon.png`、`favicon.png`：加到手機主畫面用的 App 圖示

## 評分項目（已定案）

所有項目都用點選，不用拉桿。按鈕至少 44px，方便單手操作。

- **聞香**
  - 香氣強度：無 / 淡 / 中 / 濃
  - 香型（可複選，點一下＝淡、兩下＝濃、三下取消）：綠豆、蛋白、新栽、奶香、花香、果香、清香、蜜香、焙火香，加上「＋自訂」
- **湯色**（在聞香下面）
  - 顏色（單選色塊）：淺綠、蜜綠、黃綠、金黃、蜜黃、琥珀（包種茶由淺到深，展開可看各色通常代表什麼）
  - 清澈度：清澈明亮 / 普通 / 混濁
- **滋味**
  - 苦、澀、甜：無 / 微 / 中 / 很（苦澀是橘色扣分系，甜是綠色加分系）
  - 茶湯厚度：單薄 / 適中 / 醇厚（喝起來空空、水水的選「單薄」；舊版「湯感」普通/飽滿已自動轉成適中/醇厚）
- **餘韻**：回甘（無/微/明顯）、回香（無/有/明顯，吞下後香氣回來）、生津（無/有/明顯）
- **缺點**（點一下＝微、兩下＝明顯）：菁味／生、悶味、水味、火味太重、雜味
- **整體感覺**（放在缺點之後、備註之前）：❤️ 喜歡 / 👍 還可以 / ✕ 不愛（不用專業星等）
- **備註**：自由輸入，另有快速短語按鈕

評分項目的架構參考 2026 國際精品茶葉大賞（awards.uchungtea.com）：香氣 30%、滋味 30%、韻味 20%、平衡 10%、綜合 10%。但本 App 不計算總分。

## 流程與功能

- **開場次**：輸入名稱、杯數（快選 10/15/20/25，可再 ±），之後還能加杯
- **邀請**：QR Code、6 碼代碼或連結。朋友輸入名字就能加入，不用註冊帳號（Firebase 匿名登入）
- **跳杯**：底部杯號列（上方標示「第 N 杯・共幾杯・已評幾杯」）可左右滑動、點目前杯號會開 5 欄的格子盤、在畫面上左右滑動可切換上下杯
- **盲喝**：評分時所有人都看不到製作日期，包括主揪。主揪在揭曉前到「總覽 → 大家」填上每杯的日期
- **各評各的**：揭曉前每人只看得到自己的評分，主揪按「揭曉」後大家才看得到全部
- **總覽「我的」**：從 ❤️/👍 的杯子裡依序選前三名（🥇🥈🥉）；「每杯比一比」熱圖表格，可依杯號、喜好、香氣濃、苦澀少、餘韻強排序，也可依香型篩選
- **總覽「大家」（揭曉後）**：綜合排名（🥇3 分、🥈2 分、🥉1 分，同分看 ❤️ 數）、大家都聞到的香型、爭議杯（有人 ❤️ 也有人 ✕）、每個人的感覺對照表
- **主揪權限**：加杯、填製作日期、揭曉、刪除場次（連同所有人的評分）
- **首頁**：最近的場次清單，按 ✕ 只會從自己手機的清單移除
- **外觀**：🌓 跟著手機 / ☀️ 淺色 / 🌙 深色，首頁右上角和選單都能切換
- **離線**：Firestore 離線快取，茶山上收訊不好也能評分，有網路後自動同步
- **速度**：開新場次時不等伺服器確認就直接進入；進舊場次時場次和評分同時讀取；載入超過 6 秒會顯示重試按鈕

## 資料結構（Firestore）

```
sessions/{6碼代碼}
  name, cups, revealed, hostUid, hostName, cupInfo: { "1": {date}, ... }, createdAt
  members/{uid}   name, done（已評杯數）, t
  players/{uid}   name, ratings: { "1": {like, aroma, scents{}, color, clarity, bitter, astr, sweet, thick,
                                         huigan, huixiang, shengjin, defects{}, note, t} },
                  top: [杯號, 杯號, 杯號]
```

## 安全規則重點

- 場次：登入後只能用代碼讀單一場次，不能列出所有場次；只有主揪能修改或刪除
- members：大家都看得到，只能改自己的；主揪刪除場次時可以一起刪
- players：揭曉前只能讀自己的，揭曉後大家都能讀；只能寫自己的；主揪可以刪除

## 使用注意

- **iPhone 主畫面 App 和 Safari 的身分是分開的**：從主畫面打開會被當成新的人，在 Safari 開的場次，在主畫面 App 裡不是主揪。建議統一從主畫面 App 開場次
- **更新後看不到新版**：從多工畫面把 App 完全關掉再重開；GitHub Pages 快取最多大約 10 分鐘
- **測試**：網址加 `?mock=1` 會進入模擬模式，資料只存在本機、不會上傳（另外加 `&uid=xxx` 可以模擬不同的人）
- **GitHub 授權**：Claude GitHub App 只開放 tea-rating 這一個 repo，Claude 可以直接修改並推送
